# MindMap Video —— 思维导图视频生成平台 PRD

## 1. 产品概述

### 1.1 产品定位

MindMap Video 是一个 AI 驱动的思维导图视频生成平台。用户只需输入一个主题，AI 自动生成结构化大纲（思维导图），用户在线确认和修改大纲后，一键提交后端生成带有动画演示效果的视频。整个流程以"**输入主题 → 生成大纲 → 确认修改 → 生成视频**"为核心链路，极致简化视频制作过程。

### 1.2 目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 内容创作者 | 输入选题快速生成知识科普短视频，发布到 B 站、抖音等平台 |
| 教育工作者 | 输入课程主题，AI 生成教学大纲，一键转为教学动画视频 |
| 企业培训师 | 输入培训主题，快速产出培训材料视频 |
| 个人学习者 | 输入学习主题，生成可视化复习视频 |
| 自媒体运营 | 批量输入选题，规模化生产知识类视频内容 |

### 1.3 核心价值

- **极简流程**：输入主题即可获得视频，三步完成全流程
- **AI 驱动**：AI 自动生成结构化大纲，用户只需审核修改
- **高效率**：分钟级完成传统需要数小时的视频制作
- **可定制**：大纲内容可自由编辑，视频风格可灵活配置

## 2. 核心流程

### 2.1 主流程定义

```
用户输入主题 → AI 生成大纲 → 用户确认/修改大纲 → 配置视频参数 → 提交后端生成 → 视频完成
```

### 2.2 流程详细说明

#### Step 1：输入主题

- 用户在首页或工作台输入一个主题关键词或一段描述文字
- 支持输入示例：
  - 简单关键词：`"人工智能发展史"`
  - 详细描述：`"请帮我生成一个关于 Python 入门学习路线的大纲，包含基础语法、数据结构、Web 开发等方向"`
- 可选参数（高级设置，默认折叠）：
  - 大纲层级深度（2-4 层，默认 3 层）
  - 目标受众（初学者 / 进阶 / 专业）
  - 内容风格（科普 / 学术 / 轻松 / 商务）

#### Step 2：AI 生成大纲

- 提交主题后，前端展示生成中的 loading 动画
- AI 返回结构化大纲数据，以思维导图形式可视化渲染
- 大纲数据结构示例：
  ```json
  {
    "title": "人工智能发展史",
    "children": [
      {
        "title": "起源阶段（1950s-1960s）",
        "children": [
          { "title": "图灵测试" },
          { "title": "达特茅斯会议" }
        ]
      },
      {
        "title": "发展与寒冬（1970s-1990s）",
        "children": [
          { "title": "专家系统" },
          { "title": "AI 寒冬" }
        ]
      }
    ]
  }
  ```
- 如果用户对生成结果整体不满意，可点击"重新生成"

#### Step 3：用户确认/修改大纲

- 大纲以可编辑的思维导图形式展示
- 用户可进行以下操作：
  - **编辑节点**：双击节点修改文字内容
  - **添加节点**：添加子节点或兄弟节点
  - **删除节点**：删除不需要的节点
  - **拖拽排序**：调整节点顺序和层级关系
  - **折叠/展开**：折叠或展开子节点
- 修改完成后点击"确认大纲，下一步"进入视频配置

#### Step 4：配置视频参数

- 用户在配置面板中设置视频生成参数：
  - **动画风格**：逐级展开 / 路径漫游 / 聚焦放大 / 全局总览
  - **视频参数**：分辨率（720p/1080p/2K）、画面比例（16:9/9:16/1:1）
  - **配音设置**：AI 音色选择、语速调节、背景音乐
  - **主题样式**：视觉主题（简约/科技/学术/卡通/商务）
- 提供实时缩略预览
- 对于快速使用场景，提供"一键默认配置"按钮，跳过详细设置

#### Step 5：提交生成

- 用户确认配置后点击"生成视频"
- 前端将大纲数据 + 配置参数提交至后端
- 展示生成进度页面：
  - 队列位置（如"前方 3 个任务"）
  - 预计剩余时间
  - 进度百分比 + 进度条
  - 当前处理阶段（如"正在生成语音" → "正在渲染动画" → "正在合成视频"）
- 用户可以离开页面，生成完成后通过站内通知提醒

#### Step 6：视频完成

- 生成完成后进入视频预览页
- 在线播放生成的视频
- 提供操作：
  - 下载视频（MP4）
  - 重新生成（返回配置步骤或大纲步骤）
  - 保存到我的项目
  - 分享链接

## 3. 功能模块

### 3.1 用户系统

#### 3.1.1 注册与登录

- 支持邮箱注册/登录
- 支持手机号验证码登录
- 支持第三方账号登录（微信、GitHub）
- 支持密码重置与找回
- 未登录用户可体验输入主题 + AI 生成大纲，但提交生成视频时引导登录

#### 3.1.2 用户中心

- 个人资料管理（头像、昵称、简介）
- 账户安全设置（修改密码、绑定手机/邮箱）
- 会员等级与套餐信息展示
- 使用量统计（已用/剩余视频生成次数、AI 大纲生成次数、存储空间）

### 3.2 主题输入与 AI 大纲生成

#### 3.2.1 主题输入

- 首页核心区域提供主题输入框（类似搜索引擎的居中输入体验）
- 工作台页面顶部提供快捷输入入口
- 输入框支持：
  - 短关键词输入
  - 长文本描述输入（最多 500 字）
  - 输入提示（placeholder 展示示例主题）
  - 历史主题记录（下拉显示最近输入过的主题）
- 高级选项（可折叠区域）：
  - 大纲层级深度选择
  - 目标受众选择
  - 内容风格选择

#### 3.2.2 AI 大纲生成

- 调用后端 AI 接口生成结构化大纲
- 生成过程支持流式输出（Streaming），实时渐进展示大纲节点
- 生成完成后自动渲染为思维导图可视化图形
- 提供"重新生成"按钮，可再次调用 AI 生成不同版本
- 生成失败时展示友好错误提示，引导用户重试或修改输入

### 3.3 大纲编辑器

#### 3.3.1 可视化展示

- 以思维导图形式展示 AI 生成的大纲
- 自动布局，节点分布清晰
- 支持画布操作：缩放、平移、自适应居中
- 节点按层级用不同颜色区分

#### 3.3.2 编辑功能

- 双击节点编辑文字内容
- 点击 "+" 按钮添加子节点
- 右键菜单：添加子节点、添加兄弟节点、删除节点、复制节点
- 拖拽节点调整位置和层级
- 快捷键支持：
  - `Tab`：添加子节点
  - `Enter`：添加兄弟节点
  - `Delete` / `Backspace`：删除节点
  - `Ctrl+Z`：撤销
  - `Ctrl+Y`：重做
- 每个节点可附加备注文字（用于生成视频时的旁白脚本）
- 撤销/重做操作

#### 3.3.3 大纲确认

- 编辑完成后，点击"确认大纲"按钮进入下一步
- 确认前展示大纲摘要信息：总节点数、层级深度、预估视频时长
- 如大纲为空或节点数不足（<3 个），禁用确认按钮并提示

### 3.4 视频生成配置

#### 3.4.1 动画风格

- 逐级展开：按层级逐步展开节点
- 路径漫游：镜头沿思维导图路径移动
- 聚焦放大：逐个聚焦到每个节点并放大展示
- 全局总览：先展示全貌，再逐步深入
- 每种风格提供 GIF/短视频预览效果

#### 3.4.2 视频参数

- 分辨率选择：720p / 1080p / 2K（高级套餐支持 4K）
- 画面比例：16:9（横屏）/ 9:16（竖屏）/ 1:1（方形）
- 每节点停留时长（默认 3 秒，可调整 1-10 秒）
- 总时长预估实时显示

#### 3.4.3 配音设置

- AI 语音合成：多种音色选择（男声/女声/童声等），语速可调
- 旁白内容来源：自动使用节点文字和备注，或手动编辑旁白脚本
- 背景音乐：内置音乐库选择 + 音量调节
- 静音模式：不需要配音时可关闭

#### 3.4.4 主题样式

- 内置视觉主题：简约白、科技蓝、学术灰、卡通彩、商务黑
- 背景设置：纯色、渐变色
- 全局字体选择

#### 3.4.5 快速配置

- 提供"一键默认配置"按钮，使用推荐参数直接生成
- 最近使用的配置自动记忆，下次默认复用

### 3.5 视频生成进度

- 提交后进入生成进度页面
- 展示信息：
  - 当前阶段指示器（语音生成 → 动画渲染 → 视频合成 → 完成）
  - 进度百分比和进度条
  - 预计剩余时间
- 用户可离开页面，通过以下方式接收完成通知：
  - 站内消息通知（顶部铃铛图标 + 红点）
  - 浏览器 Push 通知（需用户授权）
  - 邮件通知（可选）
- 工作台中显示"生成中"状态标签

### 3.6 视频预览与下载

- 内嵌视频播放器预览生成结果
- 操作按钮：
  - 下载视频（MP4 格式，可选清晰度）
  - 重新生成（可返回大纲编辑或仅调整配置）
  - 保存项目
  - 生成分享链接
- 视频信息展示：时长、分辨率、文件大小

### 3.7 作品管理（工作台）

#### 3.7.1 项目列表

- 以卡片视图展示所有项目
- 每张卡片展示：视频缩略图/思维导图缩略图、标题（主题名）、创建时间、状态标签
- 项目状态：
  - 草稿（大纲已确认但未生成视频）
  - 生成中（视频正在生成）
  - 已完成（视频已生成可下载）
  - 失败（生成失败，可重试）
- 支持搜索、按状态筛选、按时间排序
- 支持批量删除

#### 3.7.2 项目操作

- 查看/编辑大纲
- 重新生成视频
- 下载视频
- 删除项目
- 查看生成历史（同一大纲多次生成的记录）

## 5. 交互设计规范

### 5.1 设计原则

- **聚焦主线**：所有页面围绕"输入 → 编辑 → 配置 → 生成"主流程设计
- **步骤清晰**：全程步骤指示器（Stepper），用户随时知道自己在哪一步
- **即时反馈**：AI 生成大纲支持流式渲染，视频生成提供实时进度
- **渐进披露**：基础配置默认展示，高级选项折叠隐藏
- **容错友好**：每一步都可以返回上一步修改，生成不满意可重新生成

### 5.2 响应式设计

| 断点 | 宽度范围 | 适配策略 |
|------|---------|---------|
| Desktop | ≥1280px | 完整双栏布局（配置页左右分栏） |
| Tablet | 768px - 1279px | 可折叠面板，堆叠布局 |
| Mobile | <768px | 单栏布局，步骤分页展示 |

> 大纲编辑器在移动端提供简化编辑模式（列表大纲视图替代思维导图画布）。

### 5.3 关键交互

- **主题输入**：输入框聚焦时展示热门主题推荐，回车键直接提交
- **AI 流式生成**：大纲节点逐个出现，配合淡入动画效果
- **节点编辑**：双击进入编辑态，失焦自动保存
- **拖拽节点**：长按 150ms 后激活拖拽态，移动到目标位置松手完成重排
- **步骤导航**：已完成步骤可点击回退，未到达步骤不可点击
- **生成等待**：支持后台生成，用户可自由浏览其他页面
- **新手引导**：首次使用展示交互引导覆盖层，介绍核心三步流程

### 5.4 空状态设计

| 场景 | 空状态展示 |
|------|---------|
| 工作台无项目 | 插画 + "输入一个主题，开始你的第一个视频" + 输入框 |
| AI 生成失败 | 错误提示 + "重新生成"按钮 + "修改主题描述"建议 |
| 搜索无结果 | "没有找到相关项目" + 清除筛选按钮 |

## 6. 技术考量

### 6.1 前端技术栈建议

| 技术领域 | 推荐方案 | 说明 |
|---------|---------|------|
| 框架 | React 18+ / Next.js 14+ | SSR 支持，SEO 友好 |
| 状态管理 | Zustand | 轻量灵活，适合步骤式流程状态管理 |
| 思维导图渲染 | Canvas（Konva.js）或 SVG（D3.js） | 高性能图形渲染 |
| 动画 | Framer Motion | 步骤过渡 + 节点出现动画 |
| 样式方案 | Tailwind CSS + shadcn/ui | 快速开发 + 一致的 UI 组件 |
| AI 流式交互 | Server-Sent Events (SSE) / WebSocket | 流式接收 AI 生成大纲 |
| HTTP 请求 | Axios / TanStack Query | API 调用 + 缓存管理 |

### 6.2 核心接口设计

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/outline/generate` | POST (SSE) | 输入主题，流式返回大纲结构 |
| `/api/outline/save` | POST | 保存/更新用户修改后的大纲 |
| `/api/video/generate` | POST | 提交大纲 + 配置，创建视频生成任务 |
| `/api/video/progress/:taskId` | GET (SSE) | 获取视频生成进度（流式） |
| `/api/video/:id` | GET | 获取视频详情和下载地址 |
| `/api/projects` | GET | 获取用户项目列表 |
| `/api/projects/:id` | GET/DELETE | 获取/删除单个项目 |

### 6.3 性能指标

| 指标 | 目标值 |
|------|-------|
| 首屏加载时间（LCP） | < 2.5s |
| 可交互时间（TTI） | < 3.5s |
| AI 大纲首个节点出现 | < 2s（流式） |
| 大纲编辑器渲染帧率 | ≥ 60fps（100 节点内） |
| 自动保存延迟 | < 1s |

### 6.4 浏览器兼容性

- Chrome 90+
- Firefox 90+
- Safari 15+
- Edge 90+

- 颜色对比度满足 4.5:1 以上
- 生成进度支持 aria-live 朗读

### 7.3 SEO

- 首页支持 SSR / SSG
- 结构化数据标记（JSON-LD）
- Open Graph / Twitter Card 元标签
- 语义化 HTML 标签

## 10. 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| AI 生成大纲质量不稳定 | 用户不满意，流失 | 多次重试 + 高级选项微调 + 后续模板兜底 |
| 视频生成耗时过长 | 用户等待焦虑 | 详细进度展示 + 后台生成 + 完成通知 |
| 大量并发生成请求 | 服务器压力 | 任务队列 + 优先级（付费优先） + 弹性伸缩 |
| 输入恶意/违规内容 | 安全风险 | AI 输入内容审核 + 关键词过滤 |
| 大纲编辑器性能 | 大量节点时卡顿 | Canvas 渲染 + 节点上限提示 + 虚拟化 |
| 用户不知道输入什么 | 转化率低 | 热门主题推荐 + 示例展示 + 引导文案 |
